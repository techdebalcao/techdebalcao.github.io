Política de Privacidade

Tech de Balcão Publicador · Última atualização: 21 de novembro de 2026

Resumo: o Tech de Balcão Publicador só acessa as contas do próprio canal Tech de Balcão, só para publicar os vídeos do canal. Ele não coleta dados de espectadores nem de outras pessoas, não vende nem compartilha dados, e guarda as autorizações apenas no computador do responsável pelo canal.

1. A quem esta política se aplica

Ao aplicativo Tech de Balcão Publicador ("Aplicativo"), ferramenta interna do canal Tech de Balcão, que publica os vídeos do canal no YouTube, no Instagram e no TikTok. O tratamento de dados segue a Lei Geral de Proteção de Dados (Lei nº 13.709/2018, LGPD).

2. Quais dados o Aplicativo acessa

  • Autorizações de acesso (tokens) das contas do canal, concedidas pelo titular por meio do login oficial de cada plataforma.
  • Informações básicas das contas do canal, como o identificador, o nome de usuário e o nome do canal, usadas apenas para confirmar em qual conta publicar.
  • Os conteúdos do próprio canal (vídeos, miniaturas, legendas e textos) enviados para publicação, e as respostas das plataformas sobre o envio (por exemplo, o identificador do vídeo publicado).

O Aplicativo não acessa mensagens, listas de seguidores, comentários, dados de espectadores, dados de pagamento nem contas de outras pessoas.

3. Para que os dados são usados

Exclusivamente para enviar, agendar e publicar os conteúdos do canal nas contas do canal, e para registrar o resultado de cada envio.

4. Onde os dados ficam

As autorizações e os registros de envio ficam armazenados localmente no computador do responsável pelo canal, numa pasta separada e não compartilhada. O Aplicativo não tem servidor próprio nem banco de dados na internet.

5. Com quem os dados são compartilhados

  • Com as próprias plataformas (Google/YouTube, Meta/Instagram e TikTok), pelas APIs oficiais, para realizar a publicação.
  • Para publicar no Instagram, o arquivo de vídeo pode ser disponibilizado por alguns minutos num endereço temporário e não divulgado, por meio de um túnel da Cloudflare, apenas para que o Instagram busque o vídeo. O endereço é encerrado logo após o processamento.

Nenhum dado é vendido, alugado ou usado para publicidade.

6. Por quanto tempo

As autorizações são mantidas enquanto o Aplicativo estiver em uso e podem ser apagadas a qualquer momento. Os registros de envio são mantidos para controle do calendário do canal e também podem ser apagados.

7. Como revogar o acesso

O titular pode revogar a autorização a qualquer momento: na Conta do Google (Segurança › Apps de terceiros), no Instagram (Configurações › Apps e sites) e no TikTok (Configurações › Segurança › Apps e serviços). Ao revogar, o Aplicativo deixa de ter acesso imediatamente.

8. Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. O Aplicativo usa os Serviços de API do YouTube; consulte também a Política de Privacidade do Google.

9. Seus direitos

Nos termos da LGPD, você pode pedir confirmação, acesso, correção ou exclusão de dados pelo contato abaixo.

Privacy Policy (English)

Tech de Balcão Publicador is an internal tool that only accesses the Tech de Balcão channel's own accounts, only to publish the channel's own videos. It accesses: access tokens granted by the account holder through each platform's official login; basic account information (ID, username, channel name) to confirm the target account; and the channel's own content (videos, thumbnails, captions, texts) plus the platforms' upload responses. It does not access messages, followers, comments, viewer data, payment data or anyone else's accounts. Tokens and upload logs are stored locally on the channel owner's computer; there is no server or online database. Data is shared only with Google/YouTube, Meta/Instagram and TikTok through their official APIs; for Instagram, a video file may be exposed for a few minutes at a temporary, undisclosed Cloudflare tunnel address solely so Instagram can fetch it. No data is sold, rented or used for advertising. Access can be revoked at any time in each platform's security settings, and stored data can be deleted at any time. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: WhatsApp.
